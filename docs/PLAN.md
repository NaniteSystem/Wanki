# Wanki — план

## Режимы повторения
Обычный Anki (показал → перевернул → оценил) и режим письма поверх него. Режим включается
для колоды или для карточки и переключается прямо во время повторения.

## Оценка → FSRS
Почерк **не** влияет на интервалы:
- **< 60%** → Again (не вспомнил или написал другой знак);
- **≥ 60%** → Hard / Good / Easy по подсказкам и времени (подсказка или очень долго → Hard,
  быстро без подсказок → Easy) — `RatingPolicy`;
- **оценка почерка** хранится отдельно; знаки стабильно ниже 75 попадают в очередь
  «потренировать почерк».

## Алгоритм (`:core:scoring`)
1. Нормализация: рамка попытки вписывается в рамку эталона (109×109 у KanjiVG) с сохранением пропорций.
2. Каждый штрих пересэмплируется в 32 равноудалённые точки.
3. Венгерский алгоритм, стоимость пары = среднее расстояние между точками (минимум из прямого и
   обратного направления). Матрица (n+m)×(n+m): штрих может остаться без пары, отсюда
   пропущенные и лишние черты.
4. Метрики (веса): форма 35 (DTW по центрированным и отмасштабированным штрихам), положение и
   размер 25, количество 15, порядок 15, направление 10.
   - Все пошаговые метрики усредняются по **эталонным** штрихам, пропущенный считается за 0:
     одна идеальная черта из десяти не даёт высокой оценки.
   - Порядок = длина наибольшей возрастающей подпоследовательности / число черт. Это даёт
     и балл, и список «не на месте» для жёлтой подсветки (одна черта не на своём месте = −1/n).
   - Строгость порядка 0..1 (у арабского 0).
   - **Пропущенная или лишняя черта = неверно** (итог ≤ 59): без черты это другой знак (本→木, 王→玉).
     Отключается в настройках (`failOnMissingStroke` / `failOnExtraStroke`), например для арабского.
5. Шлюз распознавания: если распознаватель (ML Kit Digital Ink) не выдал знак в top-3, итог ≤ 59.
6. **Проверка похожих знаков**: «target в top-3» не спасает от 土↔士, 末↔未, 王↔玉, 本↔木 (ML Kit
   ставит оба в top-3, а геометрия даёт ~93–96%). Поэтому кандидаты распознавателя, стоящие выше
   цели, плюс таблица похожих знаков сравниваются по сырому геометрическому расстоянию
   (`fitDistance`: стоимость пар + разница габаритов штрихов). Если какой-то из них подходит
   лучше цели, это другой знак и итог ≤ 59.
7. Красота (только если знак засчитан): форма и положение со строгими допусками (35/25),
   пропорции (общее соотношение сторон + рамки компонентов KanjiVG) 25, ровность линий 15.

Слова: каждый знак в своей клетке, слово верно, только если верны все знаки (`WordScorer`).

## Языки
| Язык | Эталоны | Особенности |
|---|---|---|
| Японский | KanjiVG + кана | полная схема |
| Китайский | Make Me a Hanzi | полная схема |
| Корейский | ~40 чамо, рисуются один раз | слог собирается по 6 типам раскладки, оценка по чамо |
| Арабский | 28 букв × до 4 форм | порядок не штрафуется, упор на форму и распознавание; RTL, одна строка |

## Данные (Room)
```
Deck(id, parentId, name, language, settingsJson, updatedAt, deleted)
NoteType(id, name, fieldsJson, templatesJson)
Note(id, noteTypeId, fieldsJson, tags, updatedAt, deleted)
Card(id, noteId, deckId, templateOrd, writeEnabled, writeFieldOrd,
     stability, difficulty, due, state, reps, lapses, updatedAt)
ReviewLog(id, cardId, reviewedAt, rating, mode, score, beauty, durationMs, usedHint)
InkAttempt(id, reviewLogId, strokesBlob)
CharRef(char, language, strokesBlob, source)

Notebook(id, title, kind[NOTEBOOK|DIARY|SKETCH], language, updatedAt, deleted)
Page(id, notebookId, index, template, date, updatedAt, deleted)
PageInk(pageId, layersBlob, recognizedText)
PageCardLink(pageId, regionRect, cardId)
```
Штрихи хранятся в компактном бинарном формате `InkCodec` (дельты + varint; x, y, t, давление, наклон, поворот; ~7–8 байт на точку со стилусом). `InkAttempt` нужен для истории почерка по знаку.

## Синхронизация
Supabase (Postgres + Storage). UUID, `updatedAt` + `deleted` везде; конфликты разрешаются
last-write-wins по сущности (страницы целиком). `ReviewLog` только дописывается, состояние FSRS
пересчитывается из лога. `.apkg` импортируется сразу в эту схему.

## Экраны
1. Колоды. 2. Повторение (планшет: две панели; телефон: вопрос сверху, холст снизу; классика/письмо).
3. Разбор попытки (эталон полупрозрачно; зелёный/жёлтый/красный; процент, почерк, анимация порядка).
4. Браузер и редактор. 5. Статистика (удержание, прогноз, кривая почерка).
6. Тетради (перо, маркер, ластик, лассо, слои; 原稿用紙, 田字格, 원고지, RTL; лассо → карточка).
7. Настройки.
