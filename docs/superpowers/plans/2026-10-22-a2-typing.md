# Этап A2 «Печать по тексту» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A new study mode for texts, «Печать», that lets the user type a text over a faint sample or from memory. Every character is checked as it is typed, other spellings count as correct, and the hints adapt to the user's past mistakes.

**Architecture:**
- The checking logic is pure JVM code in `:core:texts`: normalisation, an incremental alignment, word history and the rating.
- Japanese readings come from Kuromoji behind a `Morphology` interface. Each piece's word list is computed when the text is saved and stored with the piece, so the history stays stable.
- The app adds DB v8 (word lists, readings, word history, unfinished attempts) and a `TypingBody` in the existing `StudyScreen`.

**Tech Stack:** Kotlin 2.3, Compose, Room, `com.atilika.kuromoji:kuromoji-ipadic:0.9.0` (Apache 2.0), JUnit 5 (core), AndroidX test (app).

**Spec:** `docs/superpowers/specs/2026-10-22-typing-practice-design.md`, sections 4–7 and 10. Section 8 (voice) belongs to stage B and is **not** in this plan. The stage A texts design (`docs/superpowers/specs/2026-10-19-memory-methods-design.md` §6) is the base being extended.

- Rating rule (spec §6):

  - errors, hints, or the sample on → Hard;
  - otherwise Good;
  - Easy only through the «Легко» button after a clean run.
- Recitation log `mode` for typed runs is `"TYPED"`.

## Review Focus

5. **Arabic typed without harakat against a vowelled text, and Russian ё typed as е, in any case.** These count as correct. Task 1: `TypingTextTest.arabicWithoutMarksMatches` and `russianYoAndCase`.

The algorithm is the one in `speech-practice.html` `align()`:
- The reading is the concatenation of `fold(unit.reading)`, with unit spans `[s, e)`.
- Costs: skip a reading char 2; a wrong or extra typed char 3.
- JUMP: a unit can also be matched whole by any `fold(form)` that ends at the current typed row. The jump edge goes from row `i − form.length`, column `s`, to row `i`, column `e`. That edge only looks back at earlier rows, so keeping rows stays valid.
- The end is the column of minimum cost in the last row, preferring the larger column on ties.
- Incremental: keep the DP rows of the previous `update`. Recompute from the first folded position where the new folded text differs, so appending a character computes one row.
- Unit judgement follows the page's `judged()`, with one change: a unit with `s < end < e` is PENDING (no colour).
- `correct` counts OK units with a non-empty reading. Mistakes are counted as on the page: per word, with a run of skipped words counting once, and each extra block counting one.
