# П2 «Порядок» — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make notebooks, boards, notes and diary days manageable over time:
- rename, duplicate, pin and delete them everywhere;
- notebook settings;
- a page grid with insert, reorder and delete;
- a 30-day trash with «Отменить»;
- thumbnails and sorting in the lists;
- notebook search that opens the right screen.

**Architecture:**
- DB v9 adds `pinned`, `createdAt` and `deletedAt` (plus page size and orientation for notebooks and pages), and repository operations on top of the existing soft-delete flags.
- One undo-snackbar helper and one long-press item menu are shared by the three lists.
- Thumbnails are rendered from stored ink on a background dispatcher into an in-memory cache; nothing new is stored.
- The page grid is a new route; page order is rewritten in one transaction.

**Tech Stack:** Kotlin 2.3, Compose, Room, androidx.ink (rendering), `sh.calvin.reorderable:reorderable:2.4.3` (Apache 2.0) for drag reordering in a lazy grid.

**Spec:** `docs/superpowers/specs/2026-10-21-early-features-rework-design.md`: §4.1 «Корзина», §4.2 «Список», «Настройки тетради», «Страницы», «Поиск», and §6, row П2. Follow-ups from П1 that belong here are listed in `docs/PROGRESS.md` «Что осталось после П1»: the restore dialog counts boards and the diary as «тетрадей», and empty lists show two «new» buttons.

## Global Constraints

- Commits stay local and are never pushed. Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never run tests on, install to, or uninstall from the physical device `320147012717`. Emulators: `wanki-phone` on `-port 5558` and `wanki-tablet` on `-port 5556`, one at a time. Never use `emulator-5554`.
- UI text is in Russian; code and comments are in English, at the surrounding density.
- Room changes need a migration with a `MigrationTest` and an exported schema. Destructive fallback is never allowed. This stage is **DB v9** (v8 is stage A2).
- Phone at 360 dp with font scale 1.3, and tablet: nothing is cut off and touch targets are ≥ 48 dp. Icons are Material Symbols vector drawables in `res/drawable`. Headers use `ScreenHeader(primary, menu)`.
- **Trash**:
  - deleted items stay **30 days**, then are removed for good together with their pages, ink and blocks;
  - every delete shows the snackbar «Удалено» with the action «Отменить»;
  - restoring a page or day whose notebook is in the trash restores the notebook too.
- **Sorting** options are «Изменено» (default), «Название» and «Создано». Pinned items always come first. The choice is remembered per list (notebooks, boards, notes).
- **Notebook settings**: title, recognition language, default paper, page size **A4 / A5**, orientation **книжная / альбомная**. Orientation applies to new pages; the current page can be switched in «Бумага…». The «Бесконечная» size is moved to П3 (Ruling, see the plan notes).
- Saving and error rules from П1 stay: errors are shown, never swallowed, and the UI resumes on main through `ui { }`.

## Review Focus

1. **Deleting the notebook that is open on another tab, or the only page of a notebook.** Nothing crashes, and a notebook never ends up with zero pages. Task 5: `PageGridTest.lastPageCannotBeDeleted`; Task 1: `RepositoryTest.deleteOpenNotebookThenRestore`.
2. **Reordering pages, then leaving at once.** The new order is kept and page indices stay dense (0..n−1, no duplicates). Task 1: `RepositoryTest.movePageKeepsDenseIndices`; Task 5: `PageGridTest.dragReorderPersists`.
3. **«Отменить» pressed after the item was already purged, or pressed twice.** No crash and no duplicate rows. Task 1: `RepositoryTest.restoreIsIdempotent`.
4. **Duplicating a notebook with many inked pages.** The copy gets new ids for every page and ink row, and editing the copy never changes the original. Task 1: `RepositoryTest.duplicateNotebookIsDeepCopy`.
5. **Old rows deleted before v9** (`deleted = 1`, no `deletedAt`). They appear in the trash with a full 30 days left from the migration, and are not purged at the first start. Task 1: `MigrationTest.migrate8To9`.

**Plan notes (decided here):**
- «Бесконечная» page size needs tiled drawing (П3 «Скорость»), so П2 stores only A4/A5 and orientation. A4 and A5 share the 1:√2 page ratio, so their difference matters only for PDF export (П3).
- Highlighting the found line on the page needs per-line recognised text (П3 «Распознанный текст»), so П2 only opens the right screen and page.
- Thumbnails are rendered, not stored: there is no stale-thumbnail bug and no migration of blobs.
