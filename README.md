# Wanki

Anki-подобное приложение для Android с режимом письма: карточку можно «ответить» рукой,
знак оценивается по штрихам, а результат идёт в FSRS.

План и принятые решения: [docs/PLAN.md](docs/PLAN.md).

## Модули

| Модуль | Статус |
|---|---|
| `:core:scoring` — нормализация, сопоставление штрихов, метрики, оценка почерка | ✅ первая версия, JVM, тесты на KanjiVG |
| `:core:ink`, `:core:srs`, `:core:data`, `:core:sync`, `:feature:*`, `:import:anki` | ещё нет |

## Сборка

```
./gradlew :core:scoring:test
```

`CalibrationReport` печатает таблицу оценок для типичных ошибок (сдвиг, дрожание,
порядок, направление, пропуск черты, похожий знак). По ней подбираются веса и допуски.
