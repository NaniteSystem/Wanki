# Wanki

Anki-подобное приложение для Android с режимом письма: карточку можно «ответить» рукой,
знак оценивается по штрихам, а результат идёт в FSRS.

План и принятые решения: [docs/PLAN.md](docs/PLAN.md).

## Модули

| Модуль | Статус |
|---|---|
| `:core:scoring` — нормализация, сопоставление штрихов, метрики, оценка почерка | ✅ JVM, тесты на KanjiVG |
| `:core:ink` — модель штрихов (x, y, t, давление, наклон, поворот) и бинарный формат | ✅ JVM, тесты |
| `:core:srs` — FSRS-6 (порт py-fsrs, сверен на 1524 повторениях) | ✅ JVM, тесты |
| `:app` — колоды и повторение, тетради, дневник, доска, заметки, настройки; Room; ML Kit | ✅ сборка + смоук-тест на эмуляторе в CI |
| `:core:sync`, `:import:anki` | ещё нет |

Скриншоты смоук-теста с эмулятора CI кладёт в ветки `ci-screenshots-phone` / `ci-screenshots-tablet`.

Захват ввода в `:app` пока лежит в пакете `app.wanki.ink`; в отдельный Android-модуль он переедет,
когда модулей с AGP станет больше одного.

## Сборка

```
./gradlew test                 # JVM-модули
./gradlew :app:assembleDebug   # нужен Android SDK (ANDROID_HOME или local.properties)
```

Без Android SDK собираются только JVM-модули. CI (GitHub Actions) гоняет тесты и выкладывает
debug-APK как артефакт сборки (`wanki-debug-apk`).

## Тестовый экран

Пишешь знак — видишь процент. Стилус рисует всегда; пальцы в режиме «авто» рисуют, пока не
появился стилус, дальше ладонь и пальцы игнорируются (можно «только стилус» / «всегда»).
Касание ладони (`FLAG_CANCELED`) отменяет черту, обратный конец пера стирает черту.
«Призрак» показывает эталон и считается подсказкой (→ Hard). После проверки: эталон
полупрозрачно, черты зелёные / жёлтые (порядок, направление) / красные (лишние), пропущенные
черты эталона пунктиром; точка в начале черты показывает направление.

`CalibrationReport` печатает таблицу оценок для типичных ошибок (сдвиг, дрожание,
порядок, направление, пропуск черты, похожий знак). По ней подбираются веса и допуски.
