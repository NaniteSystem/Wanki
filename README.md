# Wanki

Anki-подобное приложение для Android с режимом письма: карточку можно «ответить» рукой,
знак оценивается по штрихам, а результат идёт в FSRS.

План и принятые решения: [docs/PLAN.md](docs/PLAN.md).

## Модули

| Модуль | Статус |
|---|---|
| `:core:scoring` — нормализация, сопоставление штрихов, метрики, оценка почерка | ✅ JVM, тесты на KanjiVG |
| `:core:ink` — модель штрихов (x, y, t, давление, наклон, поворот) и бинарный формат | ✅ JVM, тесты |
| `:core:srs` — FSRS-6 (порт py-fsrs, сверен на 1524 повторениях) | ✅ JVM, тесты |
| `:core:texts` — тексты наизусть: деление на куски, границы слов, подсказки, первые буквы, цепочка, порции, план сабак/сабки/манзиль, оценки для FSRS | ✅ JVM, тесты |
| `:app` — колоды (вложенные, лимиты), повторение, тексты наизусть, браузер и редактор карточек, тренировка почерка, статистика, тетради, дневник, доска, заметки, настройки, напоминания, резервные копии; Room; ML Kit | ✅ сборка, JVM- и инструментальные тесты, смоук-тест на эмуляторе в CI |
| `:core:sync`, `:import:anki` | ещё нет |

Скриншоты смоук-теста с эмулятора CI кладёт в ветки `ci-screenshots-phone` / `ci-screenshots-tablet`.

Захват ввода в `:app` пока лежит в пакете `app.wanki.ink`; в отдельный Android-модуль он переедет,
когда модулей с AGP станет больше одного.

## Сборка

```
./gradlew test                          # JVM-модули и unit-тесты приложения
./gradlew :app:assembleDebug            # нужен Android SDK (ANDROID_HOME или local.properties)
./gradlew :app:connectedDebugAndroidTest  # миграции, репозиторий и смоук-тест на устройстве/эмуляторе
./gradlew :app:assembleRelease          # R8, только ARM-библиотеки
```

Release подписывается ключом из `local.properties` или переменных окружения (`WANKI_KEYSTORE`,
`WANKI_KEYSTORE_PASSWORD`, `WANKI_KEY_ALIAS`, `WANKI_KEY_PASSWORD`); без них — отладочным ключом.

Без Android SDK собираются только JVM-модули. CI (GitHub Actions) гоняет тесты и выкладывает
debug-APK как артефакт сборки (`wanki-debug-apk`).

## Тестовый экран

Пишешь знак — видишь процент. Стилус рисует всегда; пальцы в режиме «авто» рисуют, пока не
появился стилус, дальше ладонь и пальцы игнорируются (можно «только стилус» / «всегда»).
Касание ладони (`FLAG_CANCELED`) отменяет черту, обратный конец пера стирает черту.
«Призрак» показывает эталон и считается подсказкой (→ Hard). После проверки: эталон
полупрозрачно, черты зелёные / жёлтые (порядок, направление) / красные (лишние), пропущенные
черты эталона пунктиром; точка в начале черты показывает направление.

`CalibrationReport` печатает таблицу оценок для типичных ошибок (сдвиг, дрожание,
порядок, направление, пропуск черты, похожий знак). По ней подбираются веса и допуски.

## Готовые колоды

Экран «Готовые колоды» (меню «⋮» на экране колод): кана, кандзи по классам, частые японские слова, HSK 3.0,
корейская лексика по уровням. Данные собирает `tools/decks/build.py` (см. `tools/decks/README.md`).

## Тексты наизусть

Строка «Тексты» на экране колод. Стих, отрывок прозы, аят — любой текст на любом языке (арабский — справа
налево, японский и китайский делятся на слова словарём ICU). Текст делится на куски: строки стиха или
предложения прозы; куски можно склеить или разрезать, к куску — перевод или пояснение.

Новые куски учатся порциями (сколько в день — задаётся, рядом оценка нагрузки). Режимы заучивания:
- **чтение** — с озвучкой 🔊;
- **исчезающие подсказки** — уровни 0–5, слова постепенно заменяются пропусками; тап по пропуску открывает слово,
  но это подсказка, и уровень не засчитывается (использованная подсказка = рассказ не чистый);
- **первые буквы** — от слов остаются только первые буквы (для языков с пробелами можно вводить их);
- **цепочка** — по предыдущему куску вспомнить следующий;
- **рассказ** — весь кусок или текст по памяти, ошибки отмечаются.

Повторение — на выбор для каждого текста: **FSRS** по каждому куску или хифз — **сабак** (новая порция),
**сабки** (недавно выученное, окно в днях) и **манзиль** (круг по всему выученному). Расписание можно
переключить в любую сторону, история не теряется. «Рассказать весь текст» — свободная практика, на расписание
не влияет. **Свой голос**: запишите кусок или порцию и слушайте по кругу (записи хранятся на устройстве и
попадают в ручную резервную копию).
