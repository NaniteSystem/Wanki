# Данные приложения: эталоны KanjiVG и готовые колоды

```
python3 -I tools/decks/build.py            # всё
python3 -I tools/decks/build.py --only kanjivg
python3 -I tools/decks/build.py --only decks
```

Скрипт (только стандартная библиотека Python 3.9+) скачивает источники в `tools/decks/.cache/`
(не входит в git, ~400 МБ) и пишет:

- `app/src/main/assets/kanjivg/<код>.svg` — 6703 эталона черт, ужатые до того, что читает
  `KanjiVg.parse` (группа `kvg:StrokePaths_…`, вложенные `<g kvg:element>`, `<path d kvg:type>`);
  скрипт сверяет структуру с исходником;
- `app/src/main/assets/decks/catalog.json` и `<id>.tsv` — готовые колоды
  (`key\tfront\tback\ttags`, в полях `\n`, `\t`, `\\` экранированы).

Результат закоммичен, поэтому для сборки приложения скрипт запускать не нужно — только при
обновлении источников.

## Как строятся карточки
- **Кана**: 71 знак (46 + звонкие), вопрос — ромадзи и чтение по Поливанову.
- **Кандзи** (классы 1–6 и средняя школа = 2136 дзёё, по частоте): вопрос — значение и чтения он/кун.
  Русское значение берётся из слова JMdict, записанного только этим знаком (одна запись в статье) и чьи
  английские значения пересекаются со значениями KANJIDIC; иначе — английские значения KANJIDIC.
- **Слова** (6000 самых частых по рангам nf01–nf48): ответ — основная запись (или кана, если слово
  обычно пишется каной), вопрос — значение (русское из первого русского блока JMdict, очищенное от
  нумерации, ссылок «(ср.)» и японских примеров; иначе английское) и чтение.
- **HSK 3.0** (уровни 1–6 и 7–9, по частоте): вопрос — значение и пиньинь; у многозначных иероглифов —
  первое значение каждого чтения; варианты, фамилии и сокращения отбрасываются.
- **Корейский** (초급, 중급, 고급; только слова): вопрос — русский эквивалент (для счётных слов и частиц —
  русское определение), ответ — слово хангылем; порядок перемешан детерминированно.
